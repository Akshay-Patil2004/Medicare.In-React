# 🏥 Medicare.In – React Website

A modern, responsive, and user-friendly hospital website built with **React.js, JavaScript, CSS, and Vite**. CAREPOINT HOSPITAL provides an interactive interface to explore medical services, discover doctors, learn about hospital facilities, and navigate appointment and contact sections.

## 🌟 Features

- **Modern UI/UX:** Clean healthcare-focused design with a professional color palette.
- **Responsive Design:** Optimized layouts for desktop, tablet, and mobile devices.
- **Interactive Navigation:** Smooth navigation between website pages using React Router.
- **Medical Services:** Explore multiple medical departments and specialties.
- **Doctor Profiles:** Display doctor information and specialties.
- **Appointment Section:** User-friendly appointment interface.
- **Interactive Service Cards:** View additional service details through modal windows.
- **Smooth Transitions:** Hover effects and transitions for a better browsing experience.
- **Reusable Components:** Modular React components for maintainable code.
- **Dynamic UI:** React state and JavaScript logic for interactive elements.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React.js | Building reusable UI components |
| JavaScript (ES6+) | Application logic and interactivity |
| Vite | Development server and build tool |
| CSS3 | Styling, layouts, responsiveness, and transitions |
| React Router | Client-side page navigation |
| Lucide React | Icons and visual elements |
| Git & GitHub | Version control and project hosting |

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/hospital-website.git
```

### 2. Navigate to the Project Directory

```bash
cd hospital-website
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173/`.

### 5. Create a Production Build

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
